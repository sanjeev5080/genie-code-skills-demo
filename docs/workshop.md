# Nokia Workshop Agenda

---

## Intro & Capstone Setup

- Welcome, context, and goals for Nokia.
- Explain the end-to-end capstone use cases; teams pick one they'll carry through all sessions.
- Confirm access to workspace, Genie Code, SDP, Lakeview, and Lakeflow Designer.

---

## Session 1 – Genie Code ⇔ Spark Declarative Pipelines (SDP)

- Short recap of SDP and Nokia's lakehouse context.
- Use Genie Code to create/extend an SDP pipeline for the chosen use case (bronze/silver/gold, quality checks).
- Demo + hands-on use of skills/MCP for standardized pipeline patterns.

---

## Session 2 – Genie Code ⇔ AI/ML

- Start from the gold tables created in Session 1.
- Use Genie Code Agent mode to scaffold and iterate on an ML experiment (features, metrics, MLflow).
- Demo + hands-on use of skills/MCP to stamp a "standard Nokia experiment" template.

---

## Session 3 – Genie Code ⇔ Dashboard Authoring

- Take the capstone outputs and build/extend a Lakeview dashboard with Genie / dashboard authoring.
- Focus on KPI definitions, filters, and layout, driven by natural-language prompts.
- Demo + hands-on use of skills/MCP for naming conventions and standard slices.

---

## Recap, Q&A, Closeout

- Each team gives a quick walkthrough of their capstone across SDP, ML, dashboard, and LFD.
- Summarize best practices and agree on next-step enablement (e.g., deeper LFD or ML clinic, building Nokia-specific skills/MCP tools).
