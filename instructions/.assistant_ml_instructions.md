# Nokia ML Standards -- User Instructions (Template)

> **This is a template.** To create a ready-to-use version for your workspace:
> 1. Choose your approach: **direct skills** or **MCP**
> 2. Copy the matching file from `local_deployment/instructions_to_use/`
>    - `user_ml_instructions_skills.md` -- if you uploaded skills to your workspace
>    - `user_ml_instructions_mcp.md` -- if you set up a GitHub MCP connection
> 3. Fill in any remaining placeholders (username, catalog, schema, pipeline names)
> 4. Save as `/Users/{username}/.assistant_ml_instructions.md` in your workspace

**Always build ML experiments in Python notebooks.** Use MLflow for all experiment tracking. Never use print statements as a substitute for MLflow logging.

When building or modifying ML experiments, use the standards below.

---

## ML Routing

| Task | Standards to Use |
|------|-----------------|
| Any ML experiment setup | **mlflow-experiment** (apply first) |
| Feature preparation from gold tables | **feature-engineering** |
| Model evaluation, registration, deployment | **model-evaluation** |

---

## Choose ONE of the following approaches:

---

### Approach A: Direct Skills Reference (no MCP)

> Use this if you have uploaded skills directly to your Databricks workspace
> at `Workspace/.assistant/skills/` or `/Users/{username}/.assistant/skills/`.

When creating or modifying ML experiments, always use the following skills:

1. **@mlflow-experiment** -- Apply Nokia experiment naming, run logging, required params/tags, and artifact structure. Apply this first for every experiment.
2. **@feature-engineering** -- Apply standard feature derivation patterns from gold tables, train/test split, encoding, and scaling
3. **@model-evaluation** -- Apply evaluation metrics, Unity Catalog model registry, serving endpoint naming, and inference table standards

For every experiment you create:
- Always apply **@mlflow-experiment** and **@feature-engineering**
- Always apply **@model-evaluation** when registering or deploying a model

---

## Quick Reminder

- Experiment name: `/Users/{username}/nokia_{use_case}_{model_type}`
- Required params: `model_type`, `feature_version`, `data_version`, `gold_table`, `random_seed=42`
- Required tags: `team`, `use_case`, `data_source=gold_layer`, `environment`
- Always read features from gold tables — never from bronze or silver
- Train/test split: 80/20, `random_state=42`, stratify for classification
- Model registry: Unity Catalog only — `nokia_catalog.workshop.nokia_{use_case}_{model_type}`
- Serving endpoint: `nokia-{use_case}-{model_type}-endpoint`
- Always enable inference table on serving endpoints
