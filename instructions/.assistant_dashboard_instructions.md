# Nokia Dashboard Standards -- User Instructions (Template)

> **This is a template.** To create a ready-to-use version for your workspace:
> 1. Choose your approach: **direct skills** or **MCP**
> 2. Copy the matching file from `local_deployment/instructions_to_use/`
>    - `user_dashboard_instructions_skills.md` -- if you uploaded skills to your workspace
>    - `user_dashboard_instructions_mcp.md` -- if you set up a GitHub MCP connection
> 3. Fill in any remaining placeholders (catalog, schema)
> 4. Save as `/Users/{username}/.assistant_dashboard_instructions.md` in your workspace

**Always build Nokia dashboards as exec-facing Lakeview dashboards.** Every dashboard must have Nokia-standard naming, the 4 standard KPI tiles, a filter bar, standard slices, and an at-risk detail table.

When building or modifying Lakeview dashboards, use the standards below.

---

## Dashboard Routing

| Task | Standards to Use |
|------|-----------------|
| Any dashboard naming, datasets, widgets, filters | **dashboard-naming** (apply first) |
| KPI tiles, metric SQL, period-over-period comparison | **dashboard-kpis** |
| Layout, filter bar, sections, slices, color, at-risk table | **dashboard-layout** |

## Quick Reminder

- Dashboard name: `Nokia_{Use_Case}_{Audience}` (e.g. `Nokia_Churn_Analysis_Exec`)
- Dataset names: `ds_{entity}_{grain}` with SQL description comment
- Widget names: `{viz_type}_{metric}_{dimension}` (e.g. `kpi_churn_rate`, `bar_churn_by_region`)
- Filter names: `filter_{dimension}` (e.g. `filter_region`, `filter_time_period`)
- Top row: 4 KPI tiles (Total Customers, Churn Rate %, Revenue at Risk, High-Risk Count)
- Filter bar first: `filter_time_period`, `filter_region`, `filter_segment` — connected to all datasets
- Standard slices: by Region, by Product Type, by Income Tier, over Time
- Last section: at-risk customer detail table (full width)
- SQL safety: always `NULLIF` in denominators, `ROUND()` for rates and monetary values
